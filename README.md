# Orpheus Realms · Reinos de Orfeo

Sitio web oficial (ficticio) del parque temático **Orpheus Realms / Reinos de Orfeo**, operado por [Orpheus Dynamics](https://teochub.github.io/orpheus-dynamics/). Forma parte del universo del juego [The Visitor](https://teochub.github.io/the-visitor/) y está ambientado en marzo de 2089.

Sitio publicado: https://teochub.github.io/orpheus-realms/

## Estructura

```
index.html              Selector de idioma (redirige según el navegador)
404.html                Página de error
assets/
  css/style.css         Estilos del sitio
  js/main.js            Menú móvil, avisos y formularios
  img/favicon.svg
es/  y  en/             Misma estructura en cada idioma
  index.html            Inicio
  realms/               Los seis reinos, uno por archivo
  animas/               Personajes y elenco de servicio
  visit/                Horarios, mapa (map.html) y reglas (rules.html)
  tickets/              Entradas y pases
  link/                 Pulsera Orpheus Link
  help/                 Atención al Visitante y preguntas frecuentes
```

Ambos idiomas usan las mismas rutas, así el selector ES / EN lleva a la página equivalente.

## Publicar con GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Lore escondido

El sitio está escrito como si el parque siguiera funcionando. Algunos detalles son pistas para el juego: los botones de compra, las reglas sobre personas no registradas, Objetos Perdidos y la fecha de la última actualización.
